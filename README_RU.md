# Infinity Expansion 0.1.1 — тестовый исходный проект

**Это исходники, не готовый `.jar`.** Сборка требует интернет для загрузки Gradle/NeoForge и JDK 21.

## Как собрать на Windows
1. Установи IntelliJ IDEA Community и JDK 21.
2. Распакуй архив полностью в обычную папку (не запускай проект прямо внутри ZIP).
3. В IntelliJ выбери **Open** и укажи папку `InfinityExpansion_test_source` (там, где лежат `settings.gradle` и `build.gradle`).
4. Если IntelliJ спросит, выбери **Load/Trust Gradle Project**. Дождись окончания загрузки зависимостей — при первом запуске это может занять время.
5. Открой вкладку Gradle справа → Tasks → build → дважды нажми **build**.
6. Готовый файл появится в `build/libs/`. Только этот `.jar` клади в папку `mods` профиля Minecraft с NeoForge 1.21.1.

Если сборка завершится ошибкой, пришли скриншот самой нижней части окна Build — по нему можно будет исправить конкретную ошибку.

## Тестовая функциональность
- Предмет `infinityexpansion:infinity_pickaxe` и рецепт: одна обычная палка в верстаке.
- V открывает меню с двумя визуальными переключателями.
- Кирка имеет очень высокую скорость добычи и не тратит прочность при добыче/атаке.
- `fireResistant()` защищает от огня и лавы.

## Пока НЕ реализовано
- Магнит и мусорка: кнопки пока только макет меню, они ничего не меняют в игровом процессе.
- Защита выброшенного предмета от взрывов и других типов урона, кроме огня/лавы.
- Меню пока не сохраняет настройки.
- Не гарантируется мгновенное разрушение защищённых/неразрушаемых блоков или обход защиты регионов.

Цель этой версии — первый тест регистрации предмета, рецепта и открытия меню. Исходники подготовлены под Minecraft 1.21.1 / NeoForge 21.1.172 / Java 21, но сборка в этой среде не запускалась.
